Actividad B

Crear mi propio sistema difuso

Define tus entradas, salida, funciones de pertenencia y reglas directamente en MATLAB para construir tu sistema difuso (FIS).

Inicia el diseñador

Este comando abre la pantalla inicial de Fuzzy Logic Designer. Después eliges cómo crear el sistema; todavía debes configurarlo.

fuzzyLogicDesigner

El comando se puede seleccionar y copiar manualmente.

  1. Abre MATLAB Online (otra pestaña)↗.
  2. Pega el comando en Command Window y pulsa Enter.
  3. Selecciona Custom FIS en la pantalla inicial.
  4. Elige Mamdani Type-1.
  5. Indica el nombre, la cantidad de entradas y la cantidad de salidas.
  6. Configura las variables, sus rangos y las funciones de pertenencia.
  7. Define los Then/consecuentes de las reglas según tu problema.
  8. Guarda con un nombre propio en formato .fis, diferente de ventilacion_aula.fis.

Si generas combinaciones de reglas automáticamente, revisa y elige sus salidas. Los consecuentes iniciales deben corresponder a tu problema.

Abrir el ejemplo de ventilación
  1. Descarga y extrae el ZIP.
  2. Sube sus tres archivos a una misma carpeta de MATLAB Online.
  3. Abre abrir_ventilacion.m y pulsa Run.

ventilacion_aula.fis es el modelo: contiene variables, conjuntos y reglas. abrir_ventilacion.m es el lanzador que lo localiza y abre; el .fis se abre en el diseñador.

Si ya está guardado en MATLAB Drive, abre esa carpeta desde el panel Files de MATLAB Online. Ejecuta el lanzador si está junto al modelo; también puedes abrir el .fis desde Open → Open Fuzzy Inference System from File en el diseñador.

Para el siguiente comando, el .fis debe estar en la carpeta actual o en la ruta de búsqueda de MATLAB:

fuzzyLogicDesigner('ventilacion_aula.fis')

El comando se puede seleccionar y copiar manualmente.

Crear mi propio sistema

Inicia el diseñador con este comando. Abre su pantalla inicial, desde donde eliges y configuras el nuevo sistema difuso (FIS):

fuzzyLogicDesigner

El comando se puede seleccionar y copiar manualmente.

  1. Abre MATLAB Online.
  2. Pega el comando en Command Window y pulsa Enter.
  3. Selecciona Custom FIS.
  4. Elige Mamdani Type-1.
  5. Indica el nombre, la cantidad de entradas y la cantidad de salidas.
  6. Configura variables, rangos y funciones de pertenencia.
  7. Define los Then/consecuentes de las reglas.
  8. Guarda con un nombre propio en formato .fis.

Las entradas son los valores que observas; la salida es la respuesta. Los conjuntos, como Bajo o Alto, describen categorías graduales mediante funciones de pertenencia. Las reglas enlazan esas categorías con una decisión de salida.

Al cambiar un dominio, revisa los parámetros de las funciones de pertenencia para ajustarlos al nuevo rango. Si generas combinaciones de reglas, revisa y elige los consecuentes según el problema. Guarda como, por ejemplo, mi_sistema.fis para conservar el ejemplo original.

Entender el procedimiento
  1. Pertenencia: cada entrada recibe un grado entre 0 y 1 en categorías como Baja, Media o Alta.
  2. Activación: las condiciones de cada regla determinan con qué fuerza participa. En este ejemplo, AND toma el grado menor.
  3. Recorte: cada regla recorta la función de su consecuente a la altura de esa activación.
  4. Agregación: los recortes se reúnen tomando su máximo para formar una sola figura de salida.
  5. Centroide: el centro de esa figura produce el resultado numérico de ventilación.

Rule Inference: seguir un caso

Desde Design → Simulation, abre Rule Inference. En Input values, introduce valores numéricos en el orden [Temperatura Humedad Ocupacion], por ejemplo [20 50 10]. Sigue las reglas y el resultado de esa combinación.

Control Surface: explorar cambios

En Control Surface, selecciona X: Temperatura, Y: Humedad y Z: Ventilacion. Mantén Ocupacion fija en 10 personas para explorar la salida al variar las otras dos entradas.

En Reference Inputs, usa [NaN NaN 10]. Esos NaN señalan únicamente los dos ejes variables de la superficie; los valores numéricos para evaluar un caso se escriben en Input values de Rule Inference.

Guardar y descargar mi sistema
  1. En Fuzzy Logic Designer, abre Design → Save y selecciona tu diseño.
  2. Elige un nombre propio, por ejemplo mi_sistema.fis, y guarda como archivo .fis en una carpeta de MATLAB Drive.
  3. Localiza el archivo en MATLAB Drive, selecciónalo y utiliza Download para conservar una copia en tu equipo. También puedes usar clic derecho → Download en el panel Files de MATLAB Online.
Problemas frecuentes
No se reconoce fuzzyLogicDesigner
Revisa que la herramienta esté disponible y que tu cuenta tenga acceso a Fuzzy Logic Toolbox. El comando de abajo permite consultar si MATLAB identifica el Toolbox; por sí solo no garantiza que toda la ejecución funcione.
No se encuentra el .fis
Comprueba el nombre y la carpeta. Para el lanzador, conserva el .fis junto a abrir_ventilacion.m. Para el comando directo, usa la carpeta actual o la ruta de búsqueda.
Estoy intentando ejecutar el .fis
El .fis contiene el modelo, no un programa para ejecutar con Run. Ábrelo desde el diseñador o ejecuta el lanzador .m.
Las curvas quedan concentradas en un extremo
Comprueba el rango de cada variable y los parámetros de sus funciones de pertenencia; deben corresponder al mismo dominio.
Las salidas iniciales de las reglas no corresponden al problema
Revisa la columna Then y elige el consecuente correcto de cada regla. Generar combinaciones no decide sus salidas por ti.
Los resultados no aparecen en la página del proyecto
Esta integración permite abrir y utilizar MATLAB Online. Los resultados se consultan en MATLAB.
